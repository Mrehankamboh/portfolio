04

How the work is done

The page is measured first. Code comes after the layout, type, and motion are clear.

  1. 01

    Study the live page

    Record layout, type, and motion on the original before writing a line of code.

  2. 02

    Rebuild the structure

    Recreate the page in HTML, CSS, and a little JavaScript, without the original site builder.

  3. 03

    Match type and motion

    Bring spacing, type, and movement in line with the live page, then check it in the browser.
